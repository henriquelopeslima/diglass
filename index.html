Visão geral do módulo

Período: 09/09 a 21/09/2026 · Formato: encontro síncrono semanal (segundas-feiras, 18h30–22h30, via Google Meet) + conteúdo assíncrono (livros/e-books no Moodle) + questionário de fixação ao final de cada aula.

Objetivos gerais

  • Consolidar fundamentos modernos de Engenharia de Software: containerização, controle de versão distribuído, paradigma orientado a objetos e princípios de código limpo.
  • Preparar o aluno para colaborar em projetos reais usando Docker, Git/GitHub e arquitetura em camadas (Clean Architecture).
  • Desenvolver uso crítico e responsável de IA generativa como ferramenta de apoio ao desenvolvimento (nunca como substituta do raciocínio de engenharia).

Competências por aula

Aula Tema Competência-chave
1 Docker Containerização e portabilidade de ambientes
2 Git e GitHub Controle de versão e colaboração em equipe
3 Programação Orientada a Objetos Modelagem OO consistente em múltiplas linguagens
4 Engenharia Limpa Código limpo, refatoração e arquitetura SOLID/Clean Architecture
5 IA como Assistente Prompt engineering e uso crítico de ferramentas de IA generativa

Avaliação do módulo: questionário de fixação (Moodle quiz) ao final de cada aula, desafio de conhecimento na Aula 5 (10 questões), registro de presença automático e pesquisa de satisfação ao final do módulo.

Projeto prático do módulo

Ao longo das 5 aulas, construímos incrementalmente uma API para o Diário de Café — um app de barismo hobbista que cataloga cafés e insumos, registra cuppings (avaliações sensoriais) e receitas de extração. Cada aula acrescenta uma camada nova: Docker (Aula 1) → Git/GitHub e versionamento (Aula 2) → modelagem POO (Aula 3) → refatoração SOLID/Clean Architecture (Aula 4) → uso de IA para testes e refatoração (Aula 5).
