Imagens e containers

Bloco 1 · Tópico 2

Ciclo de vida

pull → run → ps → logs → exec → stop → rm

Toda a rotina do Docker cabe nessa linha.

Comandos essenciais

Comando O que faz
docker run -d -p 8080:80 nginx:alpine Cria e inicia
docker ps Lista containers
docker logs -f <nome> Acompanha logs
docker exec -it <nome> sh Abre um shell
docker rm -f <nome> Para e remove

Portas: -p 8080:80

seu computador :8080  ──►  container :80

Volumes e networks

Bloco 1 · Tópico 3

Container é descartável

Dados não moram no container.

  • Removeu o container? Perdeu o que estava dentro.
  • Solução: guardar os dados fora dele.

Onde guardar dados?

Tipo Quem gerencia Use para
Named volume Docker Dados (banco)
Bind mount Você (pasta local) Código em desenvolvimento
tmpfs Memória Dados temporários

Named volume na prática

docker run --rm -v dados:/data alpine \
  sh -c "echo oi > /data/a.txt"

docker run --rm -v dados:/data alpine cat /data/a.txt

O arquivo sobrevive: o volume vive fora do container.

Networks

Containers na mesma rede se acham pelo nome.

docker network create rede-curso
docker run -d --name web --network rede-curso nginx:alpine
docker run --rm --network rede-curso alpine wget -qO- http://web

localhost dentro do container é ele mesmo.

Docker Compose

Bloco 2 · Tópico 4

Por que Compose?

  • docker run com 8 flags não se mantém
  • O Compose descreve o ambiente em um arquivo
  • O arquivo vai para o Git: toda a equipe usa o mesmo

Anatomia do docker-compose.yml

services:
  web:
    image: nginx:alpine
    ports:
      - "8080:80"
    volumes:
      - ./site:/usr/share/nginx/html:ro

Como ler esse arquivo

  • services: cada item vira um container
  • O nome do serviço vira o hostname
  • O Compose cria a network sozinho
  • :ro monta a pasta como somente leitura

Comandos do Compose

docker compose up -d      # sobe tudo
docker compose ps         # estado
docker compose logs -f    # logs
docker compose exec web sh
docker compose down       # derruba (-v apaga volumes)

Do docker run para o Compose

Mini desafio 4 · 7 min

Traduza para um docker-compose.yml:

docker run -d --name web -p 8080:80 \
  -v $(pwd)/site:/usr/share/nginx/html:ro nginx:alpine

Extra: adicione um serviço redis e faça o web enxergá-lo pelo nome.

Stack web

Bloco 2 · Tópico 5

nginx + PHP-FPM ou nginx + Node

Por que nginx na frente?

  • Serve arquivos estáticos
  • Atua como proxy reverso
  • Habilita HTTPS no futuro
  • É o padrão em produção

Estrutura do projeto

meu-projeto/
├── docker-compose.yml
├── .docker/
│   └── nginx/default.conf
├── .gitignore
├── README.md
└── app/   (ou src/)

Node + nginx · Compose

services:
  app:
    build: ./app
    volumes:
      - ./app:/app
      - /app/node_modules
  nginx:
    image: nginx:alpine
    ports: ["8080:80"]
    volumes:
      - ./.docker/nginx/default.conf:/etc/nginx/conf.d/default.conf:ro
    depends_on: [app]

Node + nginx · nginx.conf

server {
  listen 80;
  location / {
    proxy_pass http://app:3000;
    proxy_set_header Host $host;
  }
}

app é o nome do serviço, não localhost.

PHP + nginx · Compose

services:
  app:
    build: ./.docker/php
    volumes:
      - ./src:/var/www/html
  nginx:
    image: nginx:alpine
    ports: ["8080:80"]
    volumes:
      - ./src:/var/www/html:ro
      - ./.docker/nginx/default.conf:/etc/nginx/conf.d/default.conf:ro
    depends_on: [app]

PHP + nginx · nginx.conf

server {
  listen 80;
  root /var/www/html;
  index index.php;
  location / { try_files $uri $uri/ /index.php?$query_string; }
  location ~ \.php$ {
    fastcgi_pass app:9000;
    include fastcgi_params;
    fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
  }
}

Quebre e conserte

Bloco 2 · Tópico 6 · Extra

Método de diagnóstico

  1. docker compose ps
  2. docker compose logs <serviço>
  3. docker compose exec <serviço> sh
  4. Testar a rede de dentro

De fora para dentro: navegador → porta → nginx → app.

Sintomas comuns

Sintoma Causa provável
502 Bad Gateway App não responde na porta esperada
host not found in upstream Nome do serviço errado
port is already allocated Porta ocupada no host
Container reinicia sem parar Erro no comando; ver logs
