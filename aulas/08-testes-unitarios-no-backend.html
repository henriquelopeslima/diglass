O que é (e não é) um teste unitário

Bloco 1 · Tópico 1

É

  • Testa uma unidade isolada
  • Sem banco, rede, filesystem ou relógio real
  • Roda em milissegundos
  • Determinístico: mesmo input, mesmo output

Não é

Um teste que precisa de sleep(), container rodando ou falha “às vezes”.

Isso é integração disfarçada.

PHPUnit e Jest

Bloco 1 · Tópico 2

Lado a lado

A estrutura não muda

describe/it no Jest = métodos test* no PHPUnit

Sintaxe muda, AAA continua o mesmo.

PHPUnit

final class OrderTest extends TestCase
{
    public function test_aplica_desconto_acima_de_100(): void
    {
        $order = new Order([new Item('Livro', 120.0)]);
        $total = $order->calcularTotalComDesconto();
        $this->assertEquals(108.0, $total);
    }
}

Jest / Vitest

describe('Order', () => {
  it('aplica desconto acima de R$ 100', () => {
    const order = new Order([{ nome: 'Livro', preco: 120 }]);
    expect(order.calcularTotalComDesconto()).toBe(108.0);
  });
});

Mocks e Stubs na prática

Auditoria de testes gerados por IA

Bloco 2 · Tópico 6

Asserção tautológica

it('calcula total', () => {
  const total = order.calcularTotal();
  expect(total).toBe(total); // sempre passa!
});

O maior risco de aceitar testes de IA sem revisão.

Checklist de auditoria

  1. A asserção compara com um valor esperado e conhecido?
  2. Cobre os cenários pedidos no prompt?
  3. O teste falha de verdade se eu quebrar a implementação?
